# Pathfinder Studio

Plataforma para ejecutar pipelines de IA generativa desde una interfaz web propia.

## Estructura

- `frontend/`: Aplicación React (Vite + TypeScript)
- `runtimes/`: Scripts de Kaggle (LTX, Wan, etc.)
- `supabase/`: SQL y configuración de base de datos
- `docs/`: Documentación técnica y de uso

## Estado actual

- Frontend desplegado en Cloudflare Pages
- Registro automático de runtimes en Supabase
- Pipeline LTX-2.3 integrado
